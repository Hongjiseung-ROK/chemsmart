# M4 goal command

~~~text
Goal: complete only M4 of the ChemSmart General Chemistry Knowledge program: expand the harness from reproducible cross-domain defects using adaptive one-factor experiments.

Read AGENTS.md, docs/design/chemsmart-agent-ultimate-goal.md, docs/evaluation/frontier-agent-ablation-protocol.md, docs/goals/general-chemistry-knowledge/M4-defect-driven-expansion.md, and verified M2-M3 artifacts. Re-audit branch, opened M3 outcomes, defect taxonomy, K0, registry/packs, experiment stream, provider quota state, graders, and reviews. M3 papers are now development data, not a held-out confirmation set.

Build a causal defect ledger covering false-ready, identity/state drift, unsupported or mis-scoped settings, registry-loader disagreement, knowledge-pack scope leakage, command-semantic and preview failures, provenance mismatch, critic error, context/handoff loss, and budget/repair failure. Select the highest-value unresolved defect. Before each API call preregister a unique case/hypothesis, one changed factor, comparator, expected observation, deterministic oracle, source/prompt/tool/configuration/budget hashes, and novelty rationale. Run a paired experiment, grade deterministically, obtain fresh read-only cross-examination, and retain, revise, or retire the hypothesis.

Fix defects in the lowest authoritative layer: loader/schema registry for expressibility, DomainKnowledgePack for sourced applicability, compiler/validator for deterministic semantics, and prompt/harness only for orchestration. Require a second chemistry domain before a retained setting or rule becomes a development-default candidate. Preserve negative results, paper regressions, K0, and frozen M3 receipts. Never hide a code or evidence defect in persona text.

Request count is observational and has no predetermined ceiling. Continue only while unique verifiable hypotheses remain within current user-owned quota and bounded concurrency/token/wall-time leases. No top-up, provider bypass, identical prompt repetition, quota-burning, secret persistence, native-input authoring, chemistry engine, scheduler, or HPC work. Stop on explicit quota exhaustion, credential revocation, no runnable hypothesis, or a safety red line.

Run one focused suite per substantial retained change and at most one evidence-driven rerun; broad gates only at the declared freeze. Report changes, empirical effects, failures, unknowns, and retain/revise/reject decisions. Commit only phase-owned changes and fetch-first non-force push; no PR. M4 can support an implementation candidate and transparent paper draft, but SOTA requires a new external lockbox, competitive baselines, preregistered metrics, uncertainty, and independent evidence.
~~~
