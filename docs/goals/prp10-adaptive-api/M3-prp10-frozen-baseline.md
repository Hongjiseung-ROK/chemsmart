# M3 — Frozen PRP-10 First-Pass Baseline

## Objective

Build a ten-paper, source-complete first-pass baseline for paper-to-research-plan
generality through safe preview.

## Eligibility and slots

Every paper needs legally accessible full text, SI, critical method evidence,
access/license records, and exact official single-frame XYZ. Freeze one paper
per slot: mechanism/TS/IRC; transition-metal spin/ECP; excited state;
conformer/noncovalent ensemble; thermochemistry/free energy; QM/MM/multiscale;
open shell; constrained scan; explicit cluster; and multilevel workflow.

## Required work

Freeze paper/source hashes, harness, model, prompts, skills/tools, CLI schema,
compiler, validators, network envelopes, order, and graders before opening any
outcome. For all ten papers obtain evidence claims, molecular/electronic-state
specs, loader-valid project YAML, canonical command DAG, artifact dependencies,
private safe-preview bytes and public hashes, validation/failure/analysis plan,
and the three independent reviews. Missing critical evidence or geometry ends
in an exact blocked state; it is not silently repaired.

## Gate

Report paper-level coverage, false-ready/false-success, preview validity,
repairs, cost, latency, and critic performance without claiming execution,
reproduction, general SOTA, or success from `completed`. Opening V1 outcomes
makes these papers development data; future confirmation needs a new lockbox.
Run one focused campaign suite, not broad integration gates.
