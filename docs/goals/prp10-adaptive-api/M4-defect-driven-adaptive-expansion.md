# M4 — Defect-Driven Adaptive Expansion

## Objective

Use current quota on the highest-value unique defects until a campaign terminal
condition, without a fixed API attempt cap or meaningless repetition.

## Selection loop

Prioritize severe false-ready, identity/state/provenance failures, recurrent
causal stages, repairable validator gaps, critic false negatives/positives, and
context/tool/handoff loss. For each defect:

1. register a unique hypothesis and one changed component;
2. freeze comparator, expected outcome, deterministic oracle, hashes, and
   novelty rationale;
3. run the paired case within its adaptive network envelope;
4. grade deterministically and obtain independent cross-examination;
5. retain, revise, or retire the hypothesis;
6. extend a supported effect to another chemistry domain.

Repeat a case only for preregistered uncertainty, critic recall, or
reproducibility. Stop on current-account quota exhaustion, no unique verifiable
hypothesis, credential revocation, or a safety red line. Never top up, route
around provider failure, or execute chemistry engines/HPC.

## Gate

Every retained change passes zero approval/native-input/artifact/secret bypass,
zero false success with a red deterministic gate, zero terminal mismatch, and
100% replay/rerender determinism. Report regressions and cost increases beside
benefits. After harness freeze, run the full agent, read-only Ruff,
replay/schema, citation/license/link/secret, and diff gates once each; do not
autofix or regenerate snapshots.
