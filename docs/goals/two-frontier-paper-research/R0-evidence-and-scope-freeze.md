# R0 — Evidence and Scope Freeze

## Objective

Freeze the two-frontier evidence, repository authority, provider access
boundary, and truthful implementation gap before extending runtime behavior.
R0 establishes what is known; it does not convert literature claims or API
liveness into ChemSmart efficacy.

## Required work

1. Inspect the exact branch, ancestry, dirty state, CLI schema, Runtime V2,
   command compiler, project loaders, permissions, tests, and existing receipts.
   Preserve all partial user work and keep GUI/Studio out of scope.
2. Recheck the frontier landscape against peer-reviewed papers, preprints,
   official vendor documentation, pinned open repositories, and replication
   data. Record claim-level locators, evidence class, source revision, license,
   adoption boundary, and rejected inference.
3. State explicitly that El Agente Q is a paper/data behavior benchmark with no
   verified official reusable source repository; Quntur and K3 are preprints;
   Quntur data is private reference-only under its recorded terms; and
   ChemGraph supports only conditional decomposition of independent species.
4. Validate bibliography metadata and correction/retraction status through
   Crossref, arXiv, or publisher records. An unresolved or corrected/retracted
   record is a documentation gate failure until disposition is recorded.
5. Verify DeepSeek, Elsevier, SerpAPI, and Tavily credentials with minimal
   non-secret probes. Record validity separately from entitlement and remaining
   quota. For campaign `two-frontier-s0-2026-08-01`, use only credentials
   already present in the session environment. Count initial calls and retries
   alike against 128 total DeepSeek transport attempts and 24 attempts for each
   of Elsevier, SerpAPI, and Tavily. Existing user-owned quota and those lower
   campaign caps are both hard limits; never print a key, fall back to
   Keychain, top up, change billing, retain raw full text in Git, or treat a
   search snippet as a scientific source.
6. Align `AGENTS.md`, the three project-local skills, ultimate-goal documents,
   source ledgers, and this roadmap. Record current contracts separately from
   future interfaces and unverified implementation.

ChemSmart must not contact paper authors and must not add, propose, or execute
an unreported sensitivity calculation. Missing evidence remains a blocker.

## Acceptance evidence

- Source and citation ledgers parse and every adopted claim has a locator,
  evidence class, bounded inference, and limitation.
- Repository/source pins and license decisions are explicit; no third-party
  agent or executable skill is silently vendored.
- API receipts contain provider, endpoint class, credential/entitlement status,
  quota-sufficiency outcome, and non-secret error class only.
- The gap analysis distinguishes pinned baseline, working-tree contract,
  validated behavior, and absent end-to-end capability.
- Goal commands point to the active ultimate goal and phase documents and pass
  both length limits.
- The phase-status ledger and schema parse, record `R0` as the next required
  gate, and do not admit any phase without a content-addressed completion
  receipt whose referenced artifacts exist.

## Validation and stop conditions

Use documentation parsers, link/source inspection, credential-redaction checks,
and deterministic length receipts. Do not run broad pytest or Ruff for R0.
Block on an unresolved source/license claim, secret exposure, branch custody
ambiguity that affects edits, or a request to broaden API billing authority.

R1 may start only after R0 evidence is reviewable. R0 does not authorize model
experiments, chemistry engines, HPC, training, publication, commit, or push.
