# R3 goal command

~~~text
Goal: complete R3, bounded specialist delegation, deterministic joins, and independent scientific cross-examination.

Read AGENTS.md, docs/design/chemsmart-agent-ultimate-goal.md, docs/design/paper-research-plan-v1.md, docs/goals/two-frontier-paper-research/phase-status.json, and docs/goals/two-frontier-paper-research/R3-specialists-and-reviews.md. Verify prior receipts before editing.

Adopt a computational-chemistry expert persona grounded in integrity, explicit uncertainty, constructive failure analysis, and knowledge exchange with bounded research/domain advisors. Aim for SOTA-quality scholarship but never claim SOTA without evidence.

Inspect branch/dirty state, Runtime V2, harness-profile matrix, delegation/review contracts, event store/reducer, permissions, and focused tests. Implement SpecialistTaskPacket/ResultPacket with objective, source scope, immutable inputs, dependencies, narrow tools, permission, finite budget, expected schemas/artifacts, completion predicate, one write owner, merge key/order, and repair cap. Literature tools require positive finite max_network_requests. Outputs contain observable typed artifacts, usage, rule IDs, summary, and terminal state only.

Allow specialists only for independent source curation, SI extraction, molecular-state review, independent species, project/command counterexamples, and claim-artifact audit. The coordinator alone owns canonical molecule identity, charge/multiplicity, project signatures, and final command DAG. H0/HC delegate at depth 0, HA at depth 1, HK at depth 2. No specialist may approve, execute, write native input, broaden tools, or mutate shared state.

Make joins all-or-nothing and retain exact result packets. Recompute lineage, owner, whole-family observed resource/repair budget, output-schema receipt, merge key/order, and artifact hashes from dispatched packets; reject partial-family joins and opaque validation/usage hashes. Add fresh read-only domain, command/evidence, and adversarial reviewers over frozen candidate digests. A reviewer cannot repair, approve, execute, close its own finding, or decide terminal success. Deterministic validators or independent expert adjudication arbitrate.

Seed hidden critical/noncritical faults and record recall/false rejection without exposing seeds to the evaluated agent. ChemSmart must not contact authors or add/propose/execute an unreported sensitivity calculation.

After the complete milestone run one focused delegation/merge/review/event suite and at most one evidence-based rerun. Use the question tool for material ambiguity. Report exact accepted/rejected receipts, seeded-fault results, blockers, and R4 entry conditions. Do not adopt subagents/critics from contract tests alone; no broad tests, engines, training, commit, or push without separate authority.
~~~
