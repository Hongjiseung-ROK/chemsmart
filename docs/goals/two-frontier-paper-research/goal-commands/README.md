# Copyable R0-R6 Goal Commands

Copy only the fenced body for the next incomplete phase. Each command points to
the active ultimate-goal document and its single phase contract. A new session
must inspect live state and receipts before deciding that a predecessor passed.
The [machine-readable phase-status ledger](../phase-status.json) is the current
admission authority; at this snapshot no phase has passed and R0 is next.

Use R0 through R5 in order. R6 is intentionally blocked until an independent
custodian supplies the sealed PRP-6 corpus and blind expert gold/grader. See
[length-receipt.md](length-receipt.md) for Unicode-character and UTF-8-byte
measurements; both limits are below 3,500 for every body.
