~~~text
Goal: complete R1, the strict paper and scientific-state contracts for ChemSmart.

Read AGENTS.md, docs/design/chemsmart-agent-ultimate-goal.md, docs/design/paper-research-plan-v1.md, docs/goals/two-frontier-paper-research/phase-status.json, and docs/goals/two-frontier-paper-research/R1-paper-contracts.md. Verify an R0 receipt exists; do not infer R0 completion from filenames.

Work as a transparent computational-chemistry expert. Preserve scientific identity, expose uncertainty, learn from failed gates, and use bounded advisors only with typed immutable inputs and deterministic merges. The long-term target is a SOTA-quality paper, never an unsupported SOTA claim.

Inspect branch, dirty state, Runtime V2, command compiler, project loaders, event store/reducer, and focused tests. Implement strict additive v1 contracts for PaperSourceBundle/SourceArtifact, ProtocolClaim, MolecularSystemSpec, ProjectConfigSpec, DomainKnowledgePack, RequiredProtocolCoverage, and PaperResearchPlan. Require canonical JSON, stable digests, closed references, exact geometry/atom order/units, charge, multiplicity, method, basis/ECP, dispersion, solvent, constraints, program/version, temperature/standard state, consumers, and source claim IDs.

Use exactly explicit, derived, inferred, unknown, conflict, or not_applicable. An explicit value needs a source locator; derived needs a content-addressed deterministic derivation receipt; critical not_applicable needs an applicability receipt; critical inferred/unknown/conflict deterministically blocks missing evidence. Keep plan_state separate from execution_state. A CLI limitation is blocked_capability_gap, never native-input fallback.

Extend Runtime V2 with versioned path-free research events and projection while frozen legacy JSONL replays unchanged. Advanced validation must embed actual typed plan/context and a deterministic content-addressed result; reject digest-only success, rebinding, idempotency collision, unsafe transitions, and receipt-free completion. Models must not write/edit Gaussian, ORCA, or xTB native input. ChemSmart must not contact authors or add/propose/execute an unreported sensitivity calculation.

Use inspection and deterministic receipts while editing. After the whole milestone, run one focused contract/digest/event/replay suite and at most one evidence-driven rerun. No provider calls, real engines, HPC, training, broad tests, autofix, snapshot regeneration, commit, or push without separate authority.

Use the question tool for material ambiguity. Report validated contracts, exact focused receipt, replay evidence, blockers, and R2 entry conditions; do not call a type definition an end-to-end agent.
~~~
