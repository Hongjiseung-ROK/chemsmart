# Copyable New-Session Goal Commands

Each file contains one bounded goal command for a new Codex session. The prompt
body in every file must stay below 3,500 Unicode code points and 3,500 UTF-8
bytes. Copy only the fenced body for the next incomplete phase. The new session
must inspect the live branch and phase evidence before acting; these prompts do
not prove that a predecessor phase passed.

Use M0 through M5 in order. M6 is intentionally blocked until an independent
external custodian supplies the sealed corpus and blind grader.

See [length-receipt.md](length-receipt.md) for the measured prompt-body limits.
