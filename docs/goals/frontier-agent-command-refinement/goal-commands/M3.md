command-compiled frontier runtime.

Read AGENTS.md, docs/design/chemsmart-agent-ultimate-goal.md, and
docs/goals/frontier-agent-command-refinement/{README.md,M3-approval-and-command-provenance.md}.

resource budget; invalidate on any material change.

approval must fail closed. Preserve only observable actions and opaque provider
continuation; never persist secrets or hidden reasoning. Keep chemistry
execution prohibited. Test only fake risky-tool atomicity and rejection paths.

Use inspection and deterministic receipts during implementation. Run one
focused approval/event/provenance suite only after M3 is complete, with one
evidence-driven rerun at most. Do not call models, engines, HPC, or training
tools. Use apply_patch, Conventional Commit, non-force fork push, no PR. Ask
via the question tool when available; otherwise ask the user directly and stop
only for material unresolved authority.
