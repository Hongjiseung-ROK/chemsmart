# M6 — Confirmatory Study and Paper Draft

## Objective

Run a precommitted confirmatory evaluation only after an external custodian
delivers the sealed corpus and blind grader. Draft a transparent architecture
and benchmark manuscript from the resulting evidence without claiming SOTA
unless a later, separately authorized comparison supports that term.

## Preconditions

- M5 has a complete freeze receipt and preregistration.
- An external custodian controls the held-out corpus and blind grading assets.
- Before unsealing, model, prompt, skill, CLI schema, compiler, validator,
  project fixtures, budgets, task order, and analysis plan are immutable.
- The user separately authorizes any paid API use within current quota. No
  publication, dataset release, preprint, or submission is authorized here.

## Required work

1. Run the paired 2 x 2 x 2 configurations on sealed tasks using the frozen
   command compiler for all conditions. Preserve blocked and failed outcomes.
2. Analyze paired bootstrap confidence intervals, mixed-effects models, and
   Holm-corrected component comparisons. Use deterministic graders first,
   expert rubrics second, and LLM judging only as supplemental evidence.
3. Report per-family performance, calibration, cost, latency, review quality,
   approval integrity, false passes/rejections, defect examples, negative
   results, and all exclusions. Never collapse parser acceptance, execution,
   and scientific validity into one score.
4. Promote only components that pass the preregistered safety and effect gates
   to opt-in candidates. Retain a single-agent reference path and record every
   non-passing component as experimental or disabled.
5. Prepare a reproducibility package: version pins, source/citation ledger,
   fixtures or custodian access protocol, manifests, validator outputs,
   analysis scripts, and report-generation instructions. Draft a paper focused
   on architecture, evidence, limitations, and reproducibility.

## Stop conditions

Block rather than adapt after unsealing if a required digest changes, a
validator is red, a secret/budget breach occurs, approval is bypassed, artifact
identity is uncertain, the custodian independence is lost, or an analysis
decision was not preregistered. Do not repair prompts or compiler logic using
sealed failures.

## Exit decision

The deliverable is a conservative internal draft and evidence package. It is
not a publication decision, proof of autonomous discovery, proof of
reproducibility beyond the measured protocol, or a SOTA claim.
